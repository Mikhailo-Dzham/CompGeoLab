## Анотація

У роботі реалізовано алгоритм генерації простих зіркових многокутників на множині $`S`$ із $`N`$ точок на площині шляхом полярного сортування навколо точки ядра $`z`$ зі складністю $`O(N \log N)`$. Для знаходження многокутника найменшої площі використано перебір конфігурацій для малих множин ($`N \le 20`$) та багатостартовий координатний пошук точки ядра для великих множин (до $`N = 10^4`$).

**Abstract.** This project implements an $`O(N \log N)`$ algorithm for generating simple star-shaped polygons on a planar set $`S`$ of $`N`$ points via polar sorting around a kernel point $`z`$. To find the minimum-area star-shaped polygon, the algorithm combines configuration enumeration for small point sets ($`N \le 20`$) with multi-start coordinate search for large sets (up to $`N = 10^4`$).

## 1. Вступ

Задача побудови простого многокутника на заданій множині точок площини (полігоналізація) застосовується у комп'ютерній графіці, ГІС та реконструкції контурів [1, 2]. У загальному випадку пошук простого многокутника найменшої площі є NP-складною задачею [4]. Проте звуження класу розв'язків до зіркових многокутників дозволяє будувати кожен допустимий контур за оптимальний час $`O(N \log N)`$ через полярне впорядкування вершин навколо точки ядра, що відповідає теоретичній нижній межі $`\Omega(N \log N)`$ для задач упорядкування на площині [1, 3].

**Ідея підходу:** перевірка належності кандидата $`z`$ до внутрішньої області опуклої оболонки $`CH(S)`$ за умовою максимального кутового проміжку ($`\lt \pi`$) та оптимізація координат $`z`$ для мінімізації площі многокутника зі збереженням асимптотики $`O(N \log N)`$.

## 2. Постановка задачі та математичні основи

Для скінченної множини $`S = \{p_1, p_2, \dots, p_N\}`$ на площині $`E^2`$, де $`p_i = (x_i, y_i)`$, необхідно побудувати простий зірковий многокутник $`P`$ із вершинами в усіх точках $`S`$ та знайти серед згенерованих многокутників екземпляр $`P^*`$ із мінімальною площею $`\text{Area}(P^*)`$.

* **Зірковий многокутник і ядро:** простий многокутник $`P`$ є зірковим, якщо існує точка $`z \in P`$ (точка ядра), з якої видно всі точки многокутника (відрізок $`[z, x] \subset P`$ для всіх $`x \in P`$) [1].
* **Критерій побудови:** точка $`z`$ лежить строго всередині опуклої оболонки $`CH(S)`$ тоді й лише тоді, коли максимальний кутовий проміжок між сусідніми променями з початку $`z`$ у точки $`S`$ строго менший за $`\pi`$. Якщо при цьому жодні дві точки не лежать на одному промені з $`z`$, з'єднання точок у порядку зростання кутів $`\alpha_i = \text{atan2}(y_i - z_y, x_i - z_x)`$ утворює простий зірковий многокутник без самоперетинів.
* **Обчислення площі (формула шнурування):**

$$\text{Area}(P) = \frac{1}{2} \left\vert{} \sum_{i=1}^{N} (x_i y_{i+1} - y_i x_{i+1}) \right\vert{}, \quad (x_{N+1}, y_{N+1}) = (x_1, y_1)$$

## 3. Опис алгоритму та обгрунтування складності

### 3.1. Побудова одного зіркового многокутника (`build_star_polygon`)
1. Обчислення зміщених координат $`(dx_i, dy_i)`$, полярних кутів $`\alpha_i`$ та квадратів відстаней $`d_i^2 = dx_i^2 + dy_i^2`$ — час $`O(N)`$.
2. Лексикографічне сортування точок за парою $`(\alpha_i, d_i^2)`$ — час $`O(N \log N)`$.
3. Перевірка умови кутового проміжку ($`\lt \pi`$) та колінеарності ($`\vert{}\alpha_{i+1} - \alpha_i\vert{} \gt \varepsilon`$; у разі збігу кутів виконується зсув $`z`$ на $`10^{-5}`$, не більше 6 спроб) — час $`O(N)`$.
4. Обчислення площі многокутника — час $`O(N)`$.

Сумарна складність однієї побудови: $`T_1(N) = O(N \log N)`$, пам'ять — $`O(N)`$. За редукцією до задачі сортування нижня межа становить $`\Omega(N \log N)`$ [1, 3], отже алгоритм є асимптотично оптимальним.

### 3.2. Пошук многокутника найменшої площі (`find_min_area_star_polygon`)
Прямі через пари точок $`S`$ ділять площину на $`O(N^4)`$ комірок зі сталим полярним порядком. Щоб уникнути повного перебору на великих $`N`$, застосовано два режими:
* **Малі множини ($`N \le 20`$):** перевірка сітки $`6 \times 6`$ та внутрішніх точок перетину хорд між вершинами $`S`$. Зберігаються всі унікальні зіркові многокутники та обирається конфігурація з найменшою площею.
* **Великі множини ($`20 \lt N \le 10^4`$):** багатостартовий пошук (центроїд, покоординатна медіана, сітка $`4 \times 4`$) і локальний координатний спуск за 8 напрямками навколо найкращого $`z`$. Число перевірок обмежене константою $`K \le 50`$, тому загальна складність становить $`O(K \cdot N \log N) = O(N \log N)`$.
